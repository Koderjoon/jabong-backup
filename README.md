# 25학번 자봉 장부 백업

[jabong](https://github.com/Koderjoon/jabong) 앱의 데이터를 매일 새벽 3시(한국 시간)에 받아서 `backups/날짜.json`으로 올린다.

- 파일은 **백업 암호로 암호화**되어 있다. 저장소가 공개여도 암호 없이는 내용을 볼 수 없다.
- 백업에는 명단(이름 포함)·자봉 기록·수정 이력·요청·출석·자주 쓰는 항목이 들어간다. 비밀번호, 로그인, 증빙 사진은 들어가지 않는다.
- 날짜별 파일이 계속 쌓인다. 하루 수십 KB라 몇 년을 둬도 괜찮다.

## 처음 설정 (한 번만)

1. 앱에 부총대로 로그인 → **관리 → 백업 → 자동 백업 키 새로 만들기**. 나오는 키를 복사한다. (한 번만 보인다)
2. 이 저장소 → **Settings → Secrets and variables → Actions → New repository secret**으로 네 개를 넣는다.

   | Name | Value |
   |---|---|
   | `SUPABASE_URL` | Supabase Project URL (jabong의 Vercel에 넣은 값과 같다) |
   | `SUPABASE_ANON_KEY` | Supabase anon(publishable) 키 (위와 같다) |
   | `BACKUP_KEY` | 1번에서 만든 자동 백업 키 |
   | `BACKUP_PASSWORD` | 백업 암호. 부총대만 알고, 인수인계 때 비밀번호·복구 코드와 함께 넘긴다 |

3. **Actions** 탭 → "매일 백업" → **Run workflow**로 한 번 돌려서 초록불과 `backups/` 폴더에 파일이 생기는지 확인한다.

**백업 암호를 잃어버리면 백업을 열 수 없다.** 암호를 바꾸면 그날부터의 백업만 새 암호로 열린다.

## 되살리기

1. 이 저장소의 `backups/`에서 되살릴 날짜의 파일을 연다 → 오른쪽 위 **Download raw file**.
2. 앱에 부총대로 로그인 → **관리 → 백업**에서 백업 암호를 적고, **백업 파일**에 받은 파일을 고른 뒤 **열어 보기**.
3. 지금과 무엇이 달라지는지 미리보기를 확인하고, `되살리기`라고 적은 뒤 **이 백업으로 되살리기**.
   되살리기 직전 상태는 같은 암호로 파일이 먼저 받아진다.
